# MISP feed

The tracker as a native MISP feed, generated by `scripts/build_misp_feed.py`
on every feed update. Do not edit these files by hand.

To subscribe from a MISP instance: **Sync Actions → Feeds → Add Feed**

| Field | Value |
|---|---|
| Provider | India Threat Tracker |
| Source format | MISP Feed |
| URL | `https://raw.githubusercontent.com/sohankanna/india-threat-tracker/main/misp-feed` |
| Distribution | Your choice (the events are TLP:CLEAR) |

Then enable the feed and **Fetch and store all feed data** (or enable caching
to correlate without importing).

What is in it:

* one event per fraud campaign that has indicators (domains, URLs, SHA-256
  hashes, Android package names, Telegram bot handles), with the source links;
* one event listing the actively exploited CVEs with high India relevance
  (CISA KEV + EPSS), as `vulnerability` attributes with `to_ids` off.

Values are real (re-fanged) so MISP can correlate them. Infrastructure context
(legitimate platforms a campaign abused) is never included. Only `domain`,
`url` and `sha256` attributes have `to_ids` set; package names and bot handles
are context.
